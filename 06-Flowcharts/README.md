# 🔄 Flowcharts

Welcome to the **Flowcharts** section of the **Home Automation and Vehicle Speed Detection using IoT with Google Assistant** repository.

This folder contains the flowcharts that illustrate the workflow and execution process of the **Bachelor of Technology (B.Tech) Final Year Team Project**.
