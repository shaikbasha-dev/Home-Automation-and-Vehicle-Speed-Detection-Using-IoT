# 🔧 Hardware Components

Welcome to the **Hardware Components** section of the **Home Automation and Vehicle Speed Detection using IoT with Google Assistant** repository.

This folder contains images and information about the hardware components used in the implementation of the **Bachelor of Technology (B.Tech) Final Year Team Project**.

The hardware components form the foundation of the IoT system by enabling sensing, processing, communication, and device control.

---

# 📖 Overview

The project integrates multiple electronic components to build an IoT-based home automation and vehicle speed detection system.

This folder provides a visual reference to the hardware used during project development, helping readers understand the physical implementation of the system.

---

# 🎯 Hardware Highlights

The hardware setup includes components such as:

- NodeMCU (ESP8266)
- Relay Module
- IR Sensor
- Jumper Wires
- Breadboard / PCB
- Power Supply
- Connecting Cables
- Other Supporting Electronic Components
