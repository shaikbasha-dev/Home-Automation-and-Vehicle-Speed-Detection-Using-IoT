# 🔌 Circuit Diagrams

Welcome to the **Circuit Diagrams** section of the **Home Automation and Vehicle Speed Detection using IoT with Google Assistant** repository.

This folder contains the circuit diagrams used in the implementation of the **Bachelor of Technology (B.Tech) Final Year Team Project**.

The diagrams illustrate the hardware connections between the NodeMCU (ESP8266), relay module, sensors, power supply, and other electronic components required to build the proposed IoT-based smart automation system.

---

# 📖 Overview

The circuit diagrams provide a visual representation of the electronic connections used throughout the project.

They serve as an essential reference for understanding the hardware architecture, signal flow, component interconnections, and overall system design.

These diagrams are useful for project implementation, troubleshooting, hardware verification, and educational reference.

---

# 🎯 Circuit Diagram Highlights

The circuit diagrams demonstrate:

- NodeMCU (ESP8266) Connections
- Relay Module Interface
- Sensor Connections
- Power Supply Connections
- Input and Output Interfaces
- Hardware Wiring Layout
- Component Interconnections
- IoT Device Integration
